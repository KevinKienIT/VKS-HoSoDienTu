# Quy Dinh Check Bug Ghi Bug Test Va Fix Bug

Ngay tao: 2026-04-23
Ngay cap nhat gan nhat: 2026-04-23
Sua boi agent: Codex
Muc dich: Dat bo quy dinh chuan cho viec kiem tra loi, ghi loi, kiem thu va sua loi trong V2.
Nguon prompt: `V2/00_prompt_tho/20260423_02_len_v2.md`

Tai lieu di kem:

- `20260423_02_mau_bao_cao_bug_test_fix.md`
- `20260423_03_quy_trinh_test_nhieu_vong.md`

## Dieu 1. Nguyen Tac Chung

- Moi bug phai duoc mo ta bang bang chung cu the.
- Moi fix phai di kem test hoac ly do khong the test.
- Moi ket qua test phai co pham vi ro rang.
- Moi report phai dat dung thu muc trong `V2/03_bao_cao`.

## Dieu 2. Check Bug

Khi check bug, agent phai ghi:

- muc tieu kiem tra,
- buoc tai hien,
- ket qua thuc te,
- ket qua mong doi,
- muc do anh huong,
- bang chung lien quan.

Khong duoc ket luan co bug neu chua chi ra dau hieu tai hien hoac bang chung.

## Dieu 3. Ghi Bug

Moi bug phai co cac truong:

- ma bug,
- tieu de,
- nguon prompt hoac nguon phat hien,
- buoc tai hien,
- ket qua thuc te,
- ket qua mong doi,
- muc do uu tien,
- trang thai,
- nguoi phu trach,
- file hoac khu vuc lien quan,
- ghi chu them.

## Dieu 4. Test

Moi lan test phai chi ro:

- test cai gi,
- test trong pham vi nao,
- test bang cach nao,
- ket qua dat hay khong dat,
- rui ro con lai,
- file report da tao.

Neu khong test duoc, phai ghi ro ly do va rui ro chua dong.

## Dieu 5. Fix Bug

Moi fix bug phai chi ro:

- bug nao duoc sua,
- thay doi o dau,
- tac dong phu co the co,
- test nao da chay lai,
- con viec nao can theo doi.

Khong dong bug neu chua co thong tin fix va ket qua test toi thieu.

## Dieu 6. Dong Bug

Bug chi duoc dong khi:

- da co report fix,
- da co ket qua test sau fix,
- da cap nhat report tong hop neu bug co anh huong rong.

## Dieu 7. Dat Ten Bao Cao

Ten file bao cao theo mau:

`yyyymmdd_<loai>_<noi_dung_ngan>.md`

Trong do:

- `<loai>` la `bug`, `test`, `fix`, hoac `tong_hop`
- `<noi_dung_ngan>` viet khong dau, dung dau gach duoi
